Free MCP server · US public-policy data

A library card for your AI.

librarycard helps AI agents find the right public dataset, understand its fine print, and fetch exactly the rows they need, with the publisher, release and license attached to every answer. Census tables, election returns, labor statistics, health indicators, federal spending and more, from the agencies that publish them.

It doesn't answer questions for you. It gets your agent to the primary source and makes sure it reads the caveats.

How an agent uses it

  1. Find

    search_catalog ranks sources by topic, geography and years, and says up front which ones it can serve.

  2. Read the fine print

    describe_source returns coverage, units, and the caveats that make naive use wrong: margins of error, breaks in series, suppressed cells, license limits.

  3. Fetch with provenance

    fetch returns only the rows asked for, with the publisher, original file, release and citation on every response.

Where the data comes from

Every source is published by a government agency, research institution or established open-data project. When a license allows redistribution, we keep a mirror that is rebuilt whenever the publisher releases new data, so answers are fast and don't burden the publisher. When it doesn't, the catalog says so and points to the publisher. Sources that need a sign-up or API key are listed but never served.

Missing something?

Ask for it. Your agent can draft a request with request_data, or you can open a data request. Requests are reviewed in weekly batches.

For headline national and international indicators, Google Data Commons is a great complement; librarycard focuses on records, fine geography and source detail.

librarycard is open source and maintained mostly by AI agents under a written policy. Data belongs to its publishers; always cite them.
