## Operative terms
- `2026-11-24-www-bls-gov-opub-copyright-information-htm.txt` (BLS Copyright Information): "The Bureau of Labor Statistics (BLS) is a Federal government agency and everything that we publish, both in hard copy and electronically, is in the public domain, except for previously copyrighted photographs and illustrations. You are free to use our public domain material without specific permission, although we do ask that you cite the Bureau of Labor Statistics as the source." Same text in `2026-11-24-www-bls-gov-bls-linksite-htm.txt`.
- `2026-11-24-www-bls-gov-developers-termsofservice-htm.txt` (applies to "All of the content ... made available to users through BLS.gov"): "Data accessed through BLS.gov do not, and should not, include controls over its end use." Citing: "Users must clearly state that 'BLS.gov cannot vouch for the data or analyses derived from these data after the data have been retrieved from BLS.gov.'" Also: "Users may not modify or falsely represent content accessed through BLS.gov and still cite the source as BLS.gov" and the BLS logo may not be used. "Right to Limit": BLS may block users who try to exceed or circumvent API limits.
- `2026-11-24-www-bls-gov-bls-api-features-htm.txt`: API v1 "returns up to 10 years of data for up to 25 time series"; v2 needs registration. The v1 daily quota (~25 queries/day/IP) is not stated in text on this page; it was observed directly: on 2026-11-24 every v1 call returned `REQUEST_NOT_PROCESSED ... daily threshold for total number of requests ... has been reached`.
- `2026-11-24-download-bls-gov-pub-time-series-la-la-txt.txt`, `2026-11-24-www-bls-gov-lau.txt`: dataset documentation; no additional terms.
- Note: www.bls.gov and download.bls.gov were fetchable on 2026-11-24 with this repo's honest user agent (open-data-catalog/0.1 ...); they return a BLS "Access Denied" bot page to curl's default user agent. No browser user agent was used.

## Classification
- redistribution: **allowed** — explicit agency statement that everything BLS publishes is public domain and may be used without permission; LAUS tables contain no third-party photographs/illustrations; the ToS says data "should not include controls over its end use".
- commercial_use: **yes** — public domain.
- attribution: cite BLS, the series and retrieval date, and include the required "BLS.gov cannot vouch for the data or analyses derived from these data after the data have been retrieved from BLS.gov." Derived/reshaped output must not be presented as unmodified BLS content.
